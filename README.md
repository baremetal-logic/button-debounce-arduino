# 🔘 Arduino Button Debounce
Clean and simple examples of button debouncing using Arduino.

## 📺 Video Tutorial

👉 https://www.youtube.com/your-video-link

---

## 📂 Project Structure
basic/
debounce_basic.ino → Simple debounce with millis()

function/
debounce_function.ino → Reusable debounce function

---

## ⚡ Hardware Setup

- Arduino board
- Push button
- 10kΩ resistor (pull-down)

### 🔌 Wiring

- Button → 5V
- Pin 7 → button
- 10kΩ resistor → GND

---

## 🧠 What You Will Learn

- What button bouncing is  
- Why it happens  
- How to fix it in software  
- How to write reusable embedded code
